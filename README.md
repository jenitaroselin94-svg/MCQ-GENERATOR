# QuizNova - AI MCQ Generator

## Overview

QuizNova is an AI-powered Multiple Choice Question (MCQ) Generator built using Streamlit and Hugging Face.

The application allows users to enter any topic and choose the number of questions they want. The AI then generates multiple choice questions with four options and one correct answer.

Users can answer the generated questions and submit the quiz to view their score.

---

## Features

* Enter any topic
* Select the number of questions
* Generate MCQs using AI
* Four options for each question
* One correct answer for each question
* Interactive quiz interface
* Answer selection using radio buttons
* Automatic score calculation
* Simple and user-friendly interface

---

## Technologies Used

* Python
* Streamlit
* Hugging Face Inference API
* Hugging Face Hub
* JSON

---

## AI Model

QuizNova uses the following Hugging Face model:

```text
openai/gpt-oss-120b
```

The model is used to generate topic-based multiple choice questions in JSON format.

---

## How It Works

1. Enter a topic in the input field.
2. Select the number of questions.
3. Click the **Generate MCQs** button.
4. The AI generates multiple choice questions.
5. The generated questions are displayed in the quiz section.
6. Select an answer for each question.
7. Click the **Submit Quiz** button.
8. QuizNova calculates and displays the final score.

## Hugging Face Token Setup

QuizNova requires a Hugging Face API token.

Create a folder named:

```text
.streamlit
```

Inside the folder, create:

```text
secrets.toml
```

Add your Hugging Face token:

```toml
HF_TOKEN = "YOUR_HUGGINGFACE_TOKEN"
```

Do not upload your actual API token to GitHub.

Make sure `secrets.toml` is included in `.gitignore`.


---

## Quiz and Scoring

After the questions are generated, select one option for each question.

Click:

```text
Submit Quiz
```

The application automatically compares the selected answers with the correct answers generated by the AI.

The final score is displayed in the following format:

```text
Your score: 4/5
```

---

## JSON Response Format

The AI is instructed to return the questions in JSON format.

Each question contains:

```text
question
options
answer
```

The answer contains the correct option letter:

```text
A
B
C
D
```

This JSON response is processed using Python's `json` module.

---

## Error Handling

QuizNova checks whether the user has entered a topic before generating questions.

If the topic field is empty, the application displays:

```text
Please enter a topic.
```

The application also checks whether the AI response is valid JSON. If the response cannot be parsed, an error message is displayed.
